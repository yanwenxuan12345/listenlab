# 🎧 精听实验室

面向四六级 / 雅思听力精听的单页应用。一条完整闭环：**盲听 → 做题 → 诊断 → 拆解 → 跟读 → 复听**。

结构很轻：页面全部在一个 `index.html` 里（无框架、无构建），另配一个零依赖的 `server.js`，负责托管页面 + 一个极简账号服务。**换电脑、换手机，输同一对账号密码，数据全回来。**

---

## 功能

**精听工作台（五段式）**
- **🎧 盲听全篇**：先不看原文完整听一遍，记盲听次数与摸底进度
- **⚡ 快速判断**：逐句只凭听感分类——听懂(1) / 模糊(2) / 茫然(3)，彩点进度条实时标出薄弱句
- **🔑 关键词精听**：**考点句挖空的词全部来自该篇考题的答案关键片段**（题目 evidence / 同义替换原文），带"对应第 N 题"标记；**普通句也挖空**——挖本句最重要的 1–2 个实义词（标"普通句"）；支持重听 / 提示（先给首字母再给答案）/ 直接看答案，按句记录通过情况
- **✍️ 自由精听**：听写四模式（练习 / 测试 / 抄写 / 流水播放）+ 无翻译、自动下一句、循环次数、单句循环；**划词翻译**——选中单词/短语弹浮窗，一键 AI 翻译、加入生词本、发音
- **🔁 整篇复听**：全句列表（原文+译文+听写结果+判断状态），可从头播放或只播薄弱句
- 顶部统计条：听写进度 / 已判断 / 薄弱句 / 正确率 / 考点句已过
- 逐词对照：写错的词/漏听的词自动标红；**循环听次数可控**（1/2/3/5/∞ + 整篇循环）、变速 0.5x–1.5x、美音/英音切换、长对话男女双声
- 遮盖式中文译文：点一下才露出，避免"看中文猜英文"

**错词诊断（支持连选）**
- 点第一个词 → **Shift + 点最后一个词** = 一次连选一片
- 选 2 个以上自动按**短语**合并成一条记录（例：`in terms of`），一眼看出是意群问题而不是生词没背
- 不想合并？勾选「拆开记成 N 个单词」即可
- 短语专属错因多两个：**意群没跟上**、**逻辑/信号词没抓住**
- 错词 → 记忆曲线复习队列，间隔 1/2/4/7/15/30 天

**题库与导入**
- **内置 10 套四级真题**（`mats-cet4.js` 数据文件，共 80 篇素材 / 250 题，答案多来源交叉核对）：
  2023.12 第2套、2024.06 第1/2套、2024.12 第1/2套、2025.06 第1/2套、2025.12 第1/2套、2026.06 第1套
- 导入自己的材料：原文、字幕（`-->` 时间轴）、LRC、`M:/W:` 对话、PDF
- 自动断句（`hello,world.how are you?` → 两句）、自动识别无题干的 A–D 选项块、`答案：C`、`解析：`
- 导入题目后可用 AI 选答案 + 写解析：**双轮核对**（第二轮打乱选项顺序重判）+ 原文查证，通过才标 ✅，不一致就标 ⚠ 待确认，**绝不瞎猜**

**考场模式（真题实战）**
- **做题历史**：每次交卷自动记一笔（日期 / 套题 / 得分 / 用时）；**点开任意一条 = 完整成绩页**——成绩卡 + 逐题批改（你当时选的选项标红、正确答案标绿、解析 / 信号词 / 同义替换全展开），和刚交卷时一模一样；支持一键清空
- **再练一套**：交卷后 / 回看时点「🔁 再练一套」，弹窗按素材库分类（2023.12 / 2024.06 …）挑下一套，选题下拉框同样按分类分组
- **划词翻译 + 生词本**：交卷后的成绩页里也能划词——选中即弹浮窗，可 AI 翻译、🔊 发音、＋生词本（没配 AI Key 时单词仍有本地词典释义）
- **划关键词**：电脑用鼠标拖选、**手机长按选中**题目/选项里的词 → 自动黄色高亮；划在哪个选项就标在哪个选项；重复划会提示"已划过"、只划一个字母会提示；点高亮词上的「×」取消（划词只做标记，**不会改动你选的答案**）；按题持久化保存，下次进来还在；🧹 一键清空本篇（交卷后划词自动切换为"翻译加生词"模式，不再标关键词）
- **长对话男女双声**：设置页开「对话男女声」后，对话按说话人（M/W）交替使用两个不同音色
- **解题技巧速查**：考场设置页内置同义替换等八条实战技巧，配真题例子
- 真题音频只放一遍（按考试规则），严格计时；**做完一篇再点「考场模拟」会回到选题界面，不会卡在成绩页**

**数据同步**
- 账号 / 云同步默认携带**全部数据**：听写、错题、复习队列、做题历史、判断与关键词精听记录、生词本、设置、**以及 AI Key**（设置里可关掉：关掉后 Key 只存本机不上云）

**手机端**
- 侧栏自动变成**底部标签栏**（左右滑动看全部页面），单手就能切
- 按钮 / 选项 / 输入框统一放大到 44px 以上触摸高度，选项整行可点
- 考场横幅**吸顶两行**：标题+计时一行，划词+交卷一行，答到一半也不用滚回顶部交卷
- 底部播放条自动换行并抬到标签栏上方，不挡内容；适配 iPhone 底部安全区（横屏也压扁了一档）

**其他**
- 同义替换库（可用于测试模式）、生词本、专项训练、数据看板
- 做题模式：考场模拟、严格计时
- 错题库导出 CSV（14 列，含**来源句**和**来源哪一套**）
- AI 助手（可选，填 DeepSeek API Key，兼容任何 OpenAI 兼容接口）

- **六组模块标签色**（本版的灵魂）：靛蓝 / 薄荷 / 琥珀 / 品红 / 紫 / 天蓝，落在侧栏导航图标（每个功能区一个色，选中态整行染色）、统计卡数字轮转、Hero 步骤芯片、复听序号、AI 头像、快捷选择条上——界面一眼就有分区感
- **形状**：圆角放宽到控件 12 / 卡片 20 / 面板 24 / 模态 28；层级靠柔和阴影而不是描边，素材卡悬停微微抬起

- **已知取舍**：界面文字里的 emoji 是产品既有内容声音，本次保留

## 本地运行

```bash
# 推荐：起自带的小服务（页面 + 账号同步都要它）
node server.js
# 然后访问 http://localhost:3000
```

```bash
# 也可以完全不启服务，直接用浏览器打开 index.html
start index.html        # Windows
open index.html         # macOS
# 注意：这种 file:// 方式下「账号同步」和「端到端加密云同步」用不了
#      （浏览器只在 http/https 下允许加密 API 和跨域请求）
```

端口想换就设环境变量：`PORT=8080 node server.js`。
账号数据落在 `data/store.json`（已加入 `.gitignore`，不会跟着代码走）。

## 数据怎么保证不丢：三层，按省事程度排

### 第一层：账号同步（推荐 · 零配置）

打开网站 → 点首页的 **「👤 用账号登录」** → 填一个账号名 + 密码 → **注册并进入**。

- 之后在**任何设备**（手机、公司电脑、新电脑）打开同一个链接，输同一对账号密码 → 全部数据自动就位
- 平时改动后约 **3 秒**自动上传一次；重开页面会自动比对时间戳，谁新用谁
- 账号名 3–24 字符（中英文都行），密码 ≥6 位。服务端存的是 **scrypt 加盐哈希**，不存明文密码
- 连续输错 10 次会锁定 1 分钟；登录令牌 60 天有效，用一次自动续期
- DeepSeek API Key 属于设备配置，**不上传**

**令牌为什么走四条路？** 请求头（`Authorization`）、自定义头（`X-LL-Token`）、查询串（`?token=`）、请求体（`token` 字段）。
线上网关会用自己的 JWT **覆盖** `Authorization` 头，只认它就会整个账号功能瘫痪；所以服务端把四种来源都收起来一个个试，谁能对上就用谁。
自检：`GET /api/whoami` 会报告服务端实际收到了哪几种、最终用第几个。

> **关于重新发布**：重新部署会重传代码目录，服务端账号库有可能被清空。**数据不会真丢**——每台设备的浏览器里都存着完整副本，
> 下次登录时客户端会比对时间戳、把本机较新的那份自动补传上去。想更稳妥，发布前先在「设置 → 导出全部数据」留一份 JSON。

> 账号和本机 PIN 档案是两套东西：账号登录会生成一个专属档案，本机 PIN 档案原样保留，互不覆盖。

### 第二层：本机 PIN 档案（默认就在用）

首次打开也可以只设一个 **6 位 PIN**。数据按 PIN 分区存在浏览器里，关掉再打开、重新输 PIN，数据全在。
可以建多个档案互相隔离，勾「在这台设备保持登录」就 30 天免输。

> 局限：只在这台设备的浏览器里，换设备看不到 —— 要跨设备就用第一层。

### 第三层：自建云同步（进阶 · 端到端加密）

给愿意自己搭存储的人：数据在本机用 **AES-256-GCM**（PBKDF2 15 万次迭代派生密钥）加密后再上传，云端只有密文。

- **服务端 API**
  - `POST /api/register` `{user, pass}` → 建号，返回令牌
  - `POST /api/login` `{user, pass}` → 登录，返回令牌 + 数据
  - `GET /api/data`（`Authorization: Bearer <token>`）→ 取数据
  - `PUT /api/data`（同上）→ 存数据
  - `POST /api/logout` · `POST /api/passwd` `{pass, newPass}` → 退出 / 改密码
  - `GET /api/ping` → 健康检查
- 页面接口：`GET/PUT 地址/空间ID` 返回/写入密文（kvdb.io、Firebase RTDB（后缀填 `.json`）、自建小服务都能接）

### 兜底：导出备份文件

「设置 → 导出全部数据」出一个 JSON，随便丢哪都行；新设备「导入」即可。

## 测试

```bash
# 1) 端到端（推荐先跑这个：自己会拉起 server.js，跑完自动关）
node tests/_t3.js     # 56 项：账号接口 + 登录/上传/换电脑恢复全链路

# 2) 其余测试
node tests/_t1.js     # 29 项：PIN 分区 / AES 加解密 / 连选短语 / 云适配器
node tests/_mocksync.js   # 先起本地模拟云端（另开一个终端）
node tests/_t2.js     # 124 项：登录门 / 档案隔离 / 连选入库 / 循环设置 / 云同步往返 / 考场模拟 / 成绩页回看 / 再练一套 / 划词不改答案
node tests/_t4.js     # 13 项：真题素材数据完整性（题量/选项/答案/解析/说话人标记）

# 3) 实机回归（自带启服务 + 自带无头 Chrome；没装 Chrome 会自动跳过）
node tests/_t5-kw.js  # 16 项：真实鼠标事件下，划关键词绝不误选答案 / 高亮位置 / 刷新保留
```

合计 **238 项**。`_t2.js` / `_t3.js` 都用一套轻量 DOM 桩把整个应用跑起来，并打真实 HTTP 请求（`_t3` 打真实 `server.js`），覆盖：

- 账号：注册 → 重复注册被拦 → 密码错 → 上传 → 换设备登录恢复 → 回传 → 老设备自动对齐 → 改密码后旧令牌失效
- 档案：建档案 → 听写批改 → 连选标错因 → 上传 → 清空本机 → 跨设备恢复 → 口令错被拦住
